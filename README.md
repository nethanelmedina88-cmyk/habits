# מעקב הרגלים

אפליקציית הרגלים אישית לטלפון. עובדת גם בלי אינטרנט, נשמרת בענן בחינם דרך GitHub, ונכנסת למסך הבית עם אייקון משלה.

## מה יש באפליקציה

- **היום:** סימון הרגלים בלחיצה, טבעת אחוז יומית, רצף ימים לכל הרגל, 7 הימים האחרונים בנקודות, ודירוג מצב רוח ומוטיבציה מ-1 עד 10.
- **חודש:** טבלה כמו בקובץ האקסל, עם צבע לכל שבוע, 4 מדדים עליונים ואפשרות לסמן ימים שעברו.
- **ניתוח:** גרף התקדמות יומית, אחוז לכל הרגל בצבעי אדום, צהוב וטורקיז, גרף מצב רוח ומוטיבציה, ציון שבועי ותובנות.
- **הרגלים:** הוספה, עריכה, מחיקה, סידור, אייקון, צבע, ובחירת ימים לכל הרגל (למשל בלי שבת). יש גם ספרייה של הרגלים מוכנים.

## העלאה ל-GitHub (פעם אחת, כ-5 דקות, מהמחשב)

1. נכנסים ל-github.com ומתחברים. אם אין חשבון, פותחים אחד בחינם.
2. לוחצים על הפלוס למעלה ובוחרים:
   New repository
3. בשם כותבים:
   habits
   משאירים את הבחירה
   Public
   ולוחצים:
   Create repository
4. בעמוד שנפתח לוחצים על הקישור:
   uploading an existing file
5. פותחים את קובץ ה-ZIP במחשב, וגוררים לחלון את **כל הקבצים**. לוחצים:
   Commit changes
6. נכנסים ל:
   Settings → Pages
   תחת Source בוחרים:
   Deploy from a branch
   בוחרים את הענף main ואת התיקייה root, ולוחצים:
   Save
7. מחכים דקה או שתיים ומרעננים. למעלה תופיע הכתובת של האפליקציה, בפורמט:
   https://YOUR-USERNAME.github.io/habits/

## התקנה בטלפון

1. פותחים את הכתובת ב-Chrome בטלפון.
2. לוחצים על שלוש הנקודות ובוחרים:
   Install app
   או:
   Add to Home screen
3. האייקון מופיע במסך הבית, והאפליקציה נפתחת במסך מלא.

## חיבור לענן (בתוך האפליקציה)

1. לוחצים על הכפתור "במכשיר בלבד" בפינה העליונה.
2. לוחצים "פתח את GitHub ליצירת מפתח".
3. בתוקף בוחרים:
   No expiration
   ההרשאה gist כבר מסומנת. זו ההרשאה היחידה שצריך.
4. לוחצים:
   Generate token
   מעתיקים את הקוד שמתחיל ב-ghp_ ומדביקים באפליקציה.
5. לוחצים "חבר וסנכרן". מעכשיו כל סימון נשמר גם בענן.

במכשיר נוסף (למשל המחשב) פותחים את אותה כתובת ומדביקים את אותו מפתח. הנתונים מתמזגים לבד.

## חשוב לדעת

- הנתונים נשמרים בקובץ Gist סודי בחשבון שלך. הוא לא מופיע בחיפוש ולא בפרופיל, אבל מי שמחזיק בכתובת המדויקת שלו יכול לקרוא אותו.
- המפתח נשמר רק בטלפון ונותן גישה רק ל-Gists, לא לקוד ולא לשום דבר אחר בחשבון.
- בלי אינטרנט הכל ממשיך לעבוד. השינויים עולים לענן כשהחיבור חוזר.
- יש גם גיבוי ידני לקובץ, במסך ההגדרות.
- עדכון גרסה: מעלים מחדש את הקבצים שהשתנו, ומשנים את מספר הגרסה בשורה הראשונה של sw.js.
